# СкладПилот — прототип WMS в виде анимированной стратегии

Интерактивный прототип системы управления складом: изометрическая 3D-площадка
(Three.js) с живой симуляцией погрузки/разгрузки и панелями оперативной
отчётности поверх сцены.

## Запуск

Сборка не нужна — достаточно любого статического сервера:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Three.js лежит в `vendor/`, интернет не требуется.

## Что умеет

- **3D-площадка**: здание склада с воротами (двери открываются при постановке
  машины), буферная зона и стеллажи, КПП, полоса ожидания, зарядная станция,
  деревья и забор. Грузовики подъезжают, задним ходом встают к воротам и
  уезжают; погрузчики возят паллеты между машинами и буфером.
- **Два склада** (WH-01 «Речной хаб», WH-02 «Северный DC») — симулируются
  одновременно, переключение в верхней панели.
- **KPI**: остаток и заполненность, машины на площадке и в очереди,
  своевременность, обработано паллет.
- **Карточки объектов** (клик по сцене или по таблице): склад, машина, погрузчик,
  ворота, зона хранения — статусы, прогресс, время, заряд и т.д.
- **Отслеживание рейса**: этапы от создания заказа до размещения / отправки.
- **Диспетчеризация как в стратегии**: выключите «Автоназначение ворот» и
  ставьте машины из очереди на ворота сами; отправляйте погрузчики на зарядку.
- **Новые рейсы**: отгрузка клиенту или ожидаемая поставка (в т.ч. «Пополнить»
  для позиций с низким остатком).
- **Отчёты**: сводка за смену, график паллет по часам, остатки, журнал
  операций с фильтрами, выгрузка журнала и остатков в CSV.
- **Уведомления**: низкий остаток, долгое ожидание ворот, опоздания.
- Поиск (`/`), пауза (пробел), ускорение ×3/×8, адаптив под телефон.

Управление камерой: ЛКМ — перемещение, ПКМ или Shift+ЛКМ — поворот, колесо/щипок — масштаб.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | разметка и стили интерфейса |
| `js/data.js` | справочники: склады, номенклатура, перевозчики |
| `js/sim.js` | симуляция (без 3D): рейсы, ворота, погрузчики, остатки, журнал |
| `js/scene.js` | 3D-сцена, модели, камера, выбор объектов |
| `js/main.js` | панели, отчёты, модальные окна, игровой цикл |

Данные демонстрационные и генерируются симуляцией; для реальной работы модуль
`sim.js` заменяется на API WMS с тем же набором сущностей.
